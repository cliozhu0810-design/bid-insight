# 标鉴企业微信小程序 · 免费版准备工程

当前交付是可导入开发者工具的原生入口 + web-view 分析页工程。分析复用根目录网页（PDF/DOCX/TXT、本机处理）。未注册账号，尚无体验二维码，未进行小程序实机验证、提审或正式发布。当前不是完整原生文件解析器。

## 阶段一：注册、开发和体验版

1. 用户在 https://mp.weixin.qq.com/ 选择注册小程序及企业主体，按平台要求提交企业信息并由管理员完成验证。平台显示的认证、备案与类目要求为准。不要把密码、验证码、AppSecret 放进仓库。
2. 在微信开发者工具导入本目录，选择注册得到的 AppID；替换 project.config.json 中 touristappid。没有 AppID 时只能查看代码/基础入口，不能据此宣称企业体验版已验证。
3. 准备企业可管理的 HTTPS 域名并部署根目录静态网页及完整 vendor 目录（无需启用计费服务器）。将微信提供的域名校验文件按平台要求放置，后台添加业务域名；配置 miniprogram/config.js 的 analysisUrl。GitHub Pages 上的网页可继续单独使用，不视作已配置的小程序业务域名。
4. 保持根目录 billing-config.js 的正式计费开关关闭，免费入口会隐藏收费说明。客户端 edition 参数只用于免费界面，不能当作付费服务的授权绕过。
5. 导入并编译，登录开发者工具，上传开发版本，在微信后台设置为体验版并添加测试人员。不得通过关闭域名校验来代替正式体验验收。
6. 以下实机测试完成前，不提审：iOS/Android 文件选择能否获得 PDF/DOCX/TXT；免责声明拦截；两份报价固定比例提示及原文位置；DOCX 最后保存者；通用名/模板名排除；OCR Worker/WASM 与内存；5份上限；手机从小文件逐步测试至大文件；取消/重进；网络断开；文件与文字无服务器上传；导出/打印在手机上是否可用。手机资源不足时不得承诺 200 MB /1000页均可运行。

重要：微信 web-view 的文件选择和下载行为需要实机验证。若不能可靠打开本地文件，须改做原生文件选择与独立解析/服务端任务架构，再评估上传存储、隐私说明和费用；不能把空壳入口当成已完成的分析小程序。

## 阶段二：提审、免费发布

在阶段一验收完成后：完善小程序名称、图标、简介、实际服务类目、按实际数据处理填写的隐私保护指引及平台所需备案/资质；上传版本；填写测试路径；提交审核；通过后正式发布。账号主体、运营联系人、域名均待用户补齐。平台审核结果无法预先保证。

本地预检查：`node scripts/check-release.cjs`。未配置账号/域名会明确失败，不会上传或发布代码。
