# 标鉴：原生、本地、免费开发版

导入本目录 `wechat` 到微信开发者工具。AppID 已配置为 `wx854144a0c32287f1`。无需配置业务域名、服务器、云开发或支付；不再使用 web-view。不要将 AppSecret 或私钥放入工程。

## 操作

1. 编译，阅读声明并点击“已确认”。
2. 从微信聊天选择 2–5 份 PDF / DOCX / UTF-8 TXT，也可点击“虚构示例”测试。
3. 核对公司名称、提取原文及字段归属，关闭无关候选；可粘贴公共文本进行排除。
4. 开始分析，查看共同人员/联系方式、连续重复文本、图片、报价规律和最后保存者。每项显示来源；人工关闭线索后重新计算分数。
5. 可生成本地 PDF 报告（含页码/段落、原文、图片、人工排除记录、备注），并导出 JSON 数据，由用户主动选择是否分享。清空或正常离开分析页删除本工具的临时目录；异常退出残留在下次进入时清理。不会删除用户聊天中的原始文件。

## 边界

- 本地版每份 ≤20 MB，最多5份、合计≤50 MB；PDF每份≤200页，Word/TXT≤2000段，每份文字≤30万字符。网页版本的大文件上限不适用于手机本地版。
- PDF使用文字层，展示实际页码；Word/TXT使用段落序号。系统原文件预览不自动跳转，按证据所示页码人工核查。
- 扫描件可选手机 VisionKit 本地 OCR（实验性，需真机验证）。每份最多尝试10个文字不足页，只覆盖单幅扫描图、单图≤400万像素；不支持拼接扫描或任意复杂页面。识别后必须核对文字和数字并确认，才可比对；失败页支持手工补充。未识别内容不能视为不存在问题。
- 图片最多30张/文件，单图≤400万像素；Word仅PNG/JPEG。显示缩略图及近似素材线索，不能证明同一拍摄者、设备或地点。
- Word正文不保证完整覆盖页眉、脚注、文本框、复杂表格。报价需至少3个同名、同单位、同口径可匹配的候选行；新增明确表头的PDF坐标表格、Word普通表格和制表符文本表格；按规格、单位、税口径、币种、合价数量匹配，提示固定比例、差额、一致及共同空项。重复项目不强配，合并单元格跳过；跨页无表头、多层表头、算术验算尚未覆盖。PDF元数据通常没有最后保存者，绝不用作者字段替代。
- 最后保存者属于文件属性，无正文页码。过滤通用名称、空值及用户输入的招标原模板保存者。
- 不访问工商数据，不作真实性验证或违法认定。华电试行标准仅作核查参考，评分规则不是该标准的官方认定规则。
- 不接入微信账号试用计数或收费；本版本免费，平台认证/备案/发布手续另行处理。

## 本地验证

在仓库根目录运行 `npm test` 与 `node wechat/scripts/check-release.cjs`。测试包括真实字节的虚构PDF解析、页码、报价、相同字段、Word属性提取、内存边界及规则回归。

PDF采用图片固化，适合阅读和打印，不含可检索文字层；最多160页、40MB，超限明确停止。

开发者工具中的模拟器测试不能替代 iOS / Android 真机验收。正式发布前仍须完成账号类目、备案、隐私配置、平台审核等要求；此工程不宣称已发布。

## 本地依赖

PDF.js 3.11.174（Apache-2.0）、其字体和CMap资源、web-streams-polyfill 3.3.3（MIT）。文件随包携带，不从CDN下载。字体/CMap以`.bin`打包，保留原内容。PDF模块前置本地运行时适配，禁用eval，使用同线程消息端口；streams仅调整异步迭代器原型，兼容微信编译器。

原有网页与收费后端准备代码独立保留在仓库根目录，本小程序不调用它们。开发者工具个人配置不纳入版本控制。
